# plotr

![Reviewed](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/arturcarvalho/plotr/main/.bfr/badge.json)



Drag-and-drop chart builder that emits the ggsql underneath, so any chart you build can be saved, shared, and replayed.

Not associated with the creators of ggsql.

See [MANUAL.md](./MANUAL.md) for features, setup, and usage.
